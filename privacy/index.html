Privacy

What data this site collects, stores, and transmits — and what it doesn't.

Short version: The Exposure Analyzer processes your fund selections entirely in your browser. No fund list, ticker, uploaded file, or holdings data is ever transmitted to this site's servers or any third party. The only data that leaves your device through this site is your email address, if you choose to subscribe to updates — and that goes to Buttondown, not to this site.

The Exposure Analyzer

The Analyzer is a client-side JavaScript application. When you:

  • click fund chips to select funds,
  • paste tickers into the text box, or
  • upload a CSV or text file,

that input is processed locally by JavaScript running in your browser tab. It is compared against a copy of funds.json that was downloaded to your browser when you loaded the page. None of your fund selections, ticker inputs, or file contents are sent to any server.

The Analyzer makes two network requests when it loads:

  1. /data/funds.json — the curated fund universe (a static file hosted on GitHub Pages)
  2. /data/events.json — the events timeline (a static file hosted on GitHub Pages)

These requests carry no user data. They are equivalent to your browser downloading a web page.

Email subscriptions

If you enter your email address and subscribe to updates, your email address is transmitted to Buttondown (buttondown.email), a third-party newsletter service. It is not stored by this site. Buttondown's privacy policy governs how they handle your email address. You can unsubscribe at any time via the link in any email you receive.

This site's GitHub repository does not store any email addresses. The subscriber list lives entirely with Buttondown.

Analytics

This site does not use Google Analytics, Facebook Pixel, or any other third-party analytics service. GitHub Pages may log standard server access logs (IP address, request path, timestamp) as part of its hosting infrastructure. This site does not access or control those logs.

Cookies and local storage

This site uses sessionStorage (in your browser, not on a server) to remember whether you dismissed the disclaimer bar during your current browser session. This data is cleared when you close your browser tab and is never transmitted anywhere.

No cookies are set by this site.

GitHub Pages hosting

This site is hosted on GitHub Pages. GitHub's privacy policy applies to the hosting layer. The site's source code is public on GitHub.

Changes to this policy

If this site's privacy practices change — for example, if analytics or server-side features are added — this page will be updated and a changelog entry will be added to the site's GitHub repository. The commit history serves as a verifiable record of changes.
